CLI & Agent SDK

Developer & AI Agent Quick Start

Run the exact same deterministic engines locally from your terminal, import them as standard ESM subpaths in Node.js or the browser, or connect any Model Context Protocol client (`Claude Desktop`, `Cursor`, `Windsurf`, `Hermes`) over `stdio`.

1. Install & Verify Core Engines 
git clone https://github.com/Arboracle-Ecosystem/openarbor.git
cd openarbor
npm install
npm test
npm run test:mcp
2. Compile RCA-Spec v2.0 Reports & Counter-Notices 
# Compile 10-section ASCA/RCA evidentiary report + SVG map
npx openarbor-rca compile deploy/fixtures/case-1-austin-live-oak.json --ordinance tx-austin

# Generate biomechanical preservation counter-notice (Mattheck t/R >= 0.30)
npx openarbor-rca counter-notice deploy/fixtures/case-1-austin-live-oak.json

# Compare 5-year regenerative stewardship vs. one-time removal economics
npx openarbor-rca economics deploy/fixtures/case-1-austin-live-oak.json --json
3. Start Zero-Dependency MCP Server (`JSON-RPC 2.0`) 
# Launch stdio Model Context Protocol server (6 deterministic tools)
npx openarbor-mcp

# Or invoke ESM modules directly in Node.js or browser code:
import { calculateCRZ, calculateTPZ, calculateSRZ } from 'openarbor/root-zone';
import { evaluateTreeInventory, computeMitigationPlan } from 'openarbor/ordinance-engine';
import { evaluateBiomechanicsAndRhizosphere, computeHolobiontValuation } from 'openarbor/rca-engine';
Grounded Standards

Why Deterministic Open Standards Matter in the Field

Subsurface & Structural Rigor Mattheck t/R & AS 4970 Classical arboricultural risk assessments frequently liquidate hollow veteran trees that remain mechanically stable under Claus Mattheck's hollow-cylinder buckling criterion (t/R ≥ 0.30). Open Arbor blocks un-evidenced removals and computes exact supersonic AirSpade decompaction and biochar/humate/compost prescriptions.
Statutory Traceability Zero Hardcoded City Branches Every municipal tree code in data/ordinances/ conforms to schemas/municipal-ordinance.schema.json. Multi-stem formulas, species-specific heritage thresholds, CRZ disturbance caps, and seasonal Oak Wilt windows (Ceratocystis fagacearum) trace to exact statutory sections.
Biological Equity Inversion Holobiont vs. CTLA 10th Ed. Conventional CTLA appraisals penalize ancient hollow trees via condition depreciation. Open Arbor computes both the classical CTLA Trunk Formula figure and the 200-year Holobiont Biological Equity across biomass carbon, vadose hydrology, and mycorrhizal soil infrastructure.
