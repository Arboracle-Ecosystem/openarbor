1. Single Server · 6 Harnesses

Connect Any Popular Agent Harness Over One Connection

You never wire up separate servers for root zones, city ordinances, biomechanics, or soil checks. One stdio server exposes openarbor_consult (full plain-language intake) alongside all 8 specialist tools and 3 built-in audience prompts directly via npx with zero manual repo clone.

Claude Code: One-Command MCP + Steward Subagent 
claude mcp add openarbor -- npx -y --package=github:Arboracle-Ecosystem/openarbor openarbor-mcp
Optional: install the dedicated subagent (.claude/agents/openarbor-steward.md) and skill in your project 
mkdir -p .claude/agents .claude/skills/openarbor-steward && \
curl -fsSL https://openarbor.org/agents/openarbor-steward/claude-agent.md -o .claude/agents/openarbor-steward.md && \
curl -fsSL https://openarbor.org/agents/openarbor-steward/SKILL.md -o .claude/skills/openarbor-steward/SKILL.md
