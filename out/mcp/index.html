          Register openarbor-mcp in Claude Desktop, Cursor, Windsurf, or Hermes. Because the server uses Node.js built-in modules (`node:fs`, `node:path`, `node:readline`, `node:crypto`), it starts in under 40 milliseconds with zero network calls or API keys.
        


        

          

            

              Claude Desktop (claude_desktop_config.json)
              
            

            
{
  "mcpServers": {
    "openarbor": {
      "command": "node",
      "args": [
        "/path/to/openarbor/server/mcp/openarbor-mcp.mjs"
      ]
    }
  }
}
