## The Ecosystem

Four open protocols. One regenerative operating system.

| Repository | Status | Layer | For |
|------------|--------|-------|-----|
| **[open-arbor](https://github.com/Arboracle-Ecosystem/open-arbor)** | 🟢 Active | Inventory + Business Ops | Professional arborists, tree care companies |
| **[open-nursery](https://github.com/Arboracle-Ecosystem/open-nursery)** | 🟡 Beta | Native Plant Supply | Nurseries, propagators, restoration contractors |
| **[open-forest](https://github.com/Arboracle-Ecosystem/open-forest)** | 🟡 Beta | Reforestation Design | Landscape architects, municipalities, stewards |
| **[open-sanctuary](https://github.com/Arboracle-Ecosystem/open-sanctuary)** | 🔵 Concept | Land Tenure | Landowners, stewards, impact investors |
| **[arboracle-platform](https://github.com/Arboracle-Ecosystem/arboracle-platform)** | 📚 Docs | Architecture + Strategy | Developers, architects, contributors |
