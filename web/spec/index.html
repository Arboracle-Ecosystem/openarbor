RCA-Spec v2.0 10-Section Evidentiary Report Standard & Hard Linter Rules

RCA-Spec v2.0 absorbs classical ISA (`TRAQ`, `CODIT`), ASCA (7-part evidentiary report structure), and Claus Mattheck (`t/R` hollow-shell buckling, `AS 4970` `SRZ`) rigor into open ECMAScript code while inverting the valuation polarity from tree liquidation to living holobiont equity.

The Five Mandatory Diagnostic Domains & 10-Section Compiled Report

5 Mandatory Schema Domains (`rca_assessment.schema.json`)
  1. structural_baseline: Biometrics (`dbh_cm`, height, crown spread, `plus_code_global`), `isa_traq_risk` matrix, `municipal_permit_disposition`, Shigo `CODIT` wall response, and Mattheck `sound_shell_thickness_ratio_t_over_r`.
  2. rhizosphere_and_root_collar: Root flare diameter (`DRF`), burial depth, stem-girdling root (`SGR`) count and severity, `airspade_radial_trenching_geometry`, and `CRZ`/`SRZ`/`TIZ` radii.
  3. soil_and_microbiome_baseline: Dry bulk density (`g/cm3`), steady-state infiltration (`mm/hr`), organic matter (`%`), soil pH, and `mycorrhizal_and_fungal_observations` (`F:B` ratio, guild, `iNaturalist` fungal taxa).
  4. understory_and_guild_prescription: SER reference ecosystem, engine-scaled biochar (`L`), humate (`kg`), fungal compost (`m3`), ramial woodchip mulch (`m3`), synthetic NPK/fungicide exclusion check, and native companion species guild (`open_nursery_batch_id`).
  5. outcome_monitoring_schedule: Explicit `stim_hypothesis_statement`, `stim_kill_criterion`, 12-month leading indicators, and 60-month lagging indicators with 5-dimension Sanctuary Scorecard targets.
